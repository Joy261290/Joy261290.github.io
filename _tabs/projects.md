## Featured Projects

### 1. Automated Exam Proctoring System
* **Domain:** Computer Vision & Full-Stack Development
* **Tech Stack:** React, Python (Flask API), Hugging Face Facial Recognition, MySQL
* **Overview:** Built a full-stack, real-time proctoring web application using React for the user dashboard and Python for the backend API, Integrated a pre-trained face recognition model from Hugging Face to authenticate student identity 
and flag unauthorized user presence during remote testing and Engineered database schemas in MySQL to securely store session logs, student records and system generated anomaly flags.

### 3. Analysis on the Root Causes of Flight Disruptions
* **Domain:** Business Intelligence & Big Data
* **Tech Stack:** Microsoft Power BI, Power Query (M Language), DAX, SQL
* **Overview:** Engineered an interactive Power BI dashboard analyzing over 1 million flight records to identify the primary root causes of airline delays and cancellations and Extracted and cleaned unstructured aviation data using Power Query (M/DAX), establishing clear
